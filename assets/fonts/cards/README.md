# Card typography

DejaVu Sans 2.37 (regular and bold), redistributed unmodified under the attached
Bitstream Vera / DejaVu license. Source: https://dejavu-fonts.github.io/.
The files are from Debian's `fonts-dejavu-core` package.

These fonts are bundled only for card faces so glyph widths, wrapping, resource
symbols and inequality signs remain consistent on Android and Windows. The body
uses a shared FontVariation with a small 0.2 embolden; titles and costs use bold.
No platform font substitution or per-card font shrinking is used.

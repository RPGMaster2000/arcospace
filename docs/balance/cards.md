## Draws and upgrades

Six-card hands; maximum 2 copies per identity and at most one card of each tier above Common. Tier 2 draw chance 15.0%, locked through round 5; Tier 3 chance 0.0%. Temporal Rift multiplies Tier 2 chance by 2.0. Missing eligible higher-tier bucket falls back to Common. Tune CardHand/EnemyHand in `scenes/board.tscn` or defaults in `scripts/card_hand.gd`.

Acquisitions offer 3 distinct library cards (respecting the reward tier floor), choose exactly 1; add a weighted entry to both ships' shared expedition pool. Upgrades clone player identities only: cost decreases by the table amount per level, floor 1; effects unchanged. Enemy copies and library Resources are never changed. Fully exhausted upgrade candidates grant 4 Salvage instead. Tune `CardData` fields / `ExpeditionRules.unavailable_upgrade_salvage`.

## Effect keys (`scripts/card_effects.gd`)

| Key | Resolution |
|---|---|
| `hull`, `shields`, resource or production key | Add to acting ship; excess Hull is Ablative Plating |
| `damage`, `pierce` | Damage; floor(damage × pierce) bypasses Shields, remaining damage consumes Shields then Hull/plating |
| `break_shields` | Remove specified enemy Shields before damage |
| `drain`, `steal` | Remove available enemy resource (floor 0); steal adds the amount actually removed to actor |
| `sabotage` | Lower every enemy production by amount; floor 1 |
| `production_other` | Add specified production/resource only if corresponding resource differs from card family |
| `random_gain` | Uniformly choose one of 3 resources and add amount |
| `random_gain_other`, `random_gain_range_other` | Uniformly choose one of 2 other families; fixed amount or inclusive uniform integer range |
| `swap_shields` | Exchange current Shield amounts |
| `shield_collapse` | Remove all enemy Shields; at or above threshold, stated chance of regular self-damage |
| `shield_collapse_below` | Remove all enemy Shields strictly below threshold |
| `self_damage` / `self_damage_regular` | Direct Hull/plating loss / Shield-first damage |

Discard gives floor(cost / 3) matching resources (`scripts/board.gd`). Extra actions grant no turn income or Emergency Jump charge. **Planned, not implemented:** Tier 3 card library, deck trimming. Pirate rewards currently use Uncommon-or-better, the highest populated tier; no empty rare selection screen.
